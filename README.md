## 🚀 Auto-Push to GitHub

Este proyecto incluye un sistema de auto-push para subir cambios automáticamente a GitHub.

### Uso Rápido:

**Opción 1: Push Manual**
```bash
# Doble clic en:
auto-push.bat
```

**Opción 2: Auto-Push Continuo (cada 5 minutos)**
```bash
# Doble clic en:
start-git-watcher.bat
```
