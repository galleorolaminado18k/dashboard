# ⚡ PASO 1 - OBTENER WAHA_API_KEY DEL VPS

## 📋 Ejecutar en el VPS

```bash
grep WAHA_API_KEY /opt/baileys/.env
```

**Copiar el valor completo que aparece después del `=`**

Ejemplo:
```
WAHA_API_KEY=c951554f59644aa3a1b3af3ad1c0a37c
```

---

## ✅ Después de ejecutar

Guarda ese valor para usarlo en el Paso 2 (Vercel).

**¡IMPORTANTE!** El valor debe ser exactamente el mismo en VPS y Vercel.
