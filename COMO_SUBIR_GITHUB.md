## 🎯 OPCIÓN 1: PUSH MANUAL (Más Control)

### 📝 Pasos:
1. Guarda tus archivos (Ctrl+S)
2. Haz doble clic en: **`auto-push.bat`**
3. Espera 5 segundos
4. ¡Listo! Cambios en GitHub

### ✅ Cuándo usar:
- Cuando terminas una funcionalidad
- Antes de cerrar el proyecto
- Cuando quieres control total

---

## 🔄 OPCIÓN 2: AUTO-PUSH (Sin Pensar)

### 📝 Pasos:
1. Haz doble clic en: **`start-git-watcher.bat`**
2. Minimiza la ventana (NO la cierres)
3. Trabaja normalmente
4. Cada 5 minutos se sube automáticamente

### ✅ Cuándo usar:
- Desarrollo activo todo el día
- No quieres pensar en Git
- Quieres backup automático
